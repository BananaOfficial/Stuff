01 / How

The whole trick

A request arrives with a domain name. The worker takes that name and looks for the matching JSON file in the registry. The HTML inside that record becomes the response.

domain → JSON record → HTML response
no database lookup required for the public path
02 / Registry

Files are the registry.

Registered domains live as individual JSON files. Ownership information sits beside the content so the record can be managed without inventing another storage layer.

domains/example.json registry record 
{
  "html": "<h1>hello</h1>",
  "owner": "BananaOfficial"
}
