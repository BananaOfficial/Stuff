RequestTimeout infrastructure.

RequestTimeout Hosting is a small registry-backed hosting layer. A domain maps to a record, the worker reads that record, and the stored HTML is served. Nothing here needs a dashboard to make sense.

Request path

One request. Three layers.

GET /{domain}
01
Client
Browser requests a registered domain.
02
Worker
The edge endpoint resolves the domain record.
03
Registry
GitHub stores the record containing the HTML.
Registry

The registry is just files.

Every registered domain has its own JSON record in the hosting repository. The worker uses the domain from the URL as the filename, reads the record, then returns its html field.

domains/banana.jsonregistry record 
{
  "html": "<!doctype html> ...",
  "owner": "BananaOfficial"
}
Principle

Keep the public serving path boring. The interesting part is the infrastructure behind it.

registry → worker → response
